# WASEEM MEDICAL PRO
نظام إدارة مركز طبي/علاج طبيعي — نسخة أولية احترافية قابلة للتحويل إلى APK.

## المزايا
- تسجيل دخول محلي.
- لوحة تحكم.
- إدارة المرضى.
- إنشاء الباقات ومتابعة الجلسات.
- خصم الجلسة تلقائياً وتحديث المتبقي.
- تنبيهات قرب انتهاء الباقة وانتهائها.
- إدارة المواعيد وحالاتها.
- مركز تحكم بالإشعارات.
- قوالب رسائل قابلة للتخصيص.
- واتساب/SMS بوضع التجهيز، مع طبقة قنوات قابلة للربط لاحقاً بـ WhatsApp Business API وSMS Gateway.
- إعدادات المركز والشعار.
- تخزين البيانات محلياً عبر LocalStorage كبداية.

## التشغيل
افتح `index.html` في المتصفح.

لتحويله لاحقاً إلى APK يمكن تغليفه بـ Capacitor أو ربطه بواجهة خلفية وقاعدة بيانات حقيقية.
